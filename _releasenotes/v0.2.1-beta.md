# Burnrate 0.2.1-beta

- Removed Kimi and Gemini from the macOS provider menu and menu bar source settings.
- Changed the default menu bar icon to a flame, while retaining the warning at 90% usage.
- Enabled release builds with Swift command-line tools by excluding design-time previews.
- Added explicit credits for Common Tools Co., Rich Sison, and the original Burnrate contributors.
- Disabled the original project's automatic update feed for this independently maintained fork.

Based on [wrnsnng/burnrate](https://github.com/wrnsnng/burnrate). See [CREDITS.md](../CREDITS.md).
