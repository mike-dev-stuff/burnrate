## Changes in this fork

- Simplified the macOS provider menu to Claude and Codex.
- Replaced the default robot menu bar icon with a flame, retaining the high-usage warning.
- Made SwiftUI previews debug-only so release builds work with the Swift command-line tools.
- Disabled the upstream updater configuration so this fork cannot be replaced by an upstream release.

The original project's README identifies Burnrate as MIT licensed. Its license statement is retained in this repository.
